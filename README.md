# COSMOS
### Beyond what the eye can see.

COSMOS is a public-facing space exploration project for the NASA Space Apps Challenge 2026. It aims to make NASA's SPHEREx infrared sky survey easier to explore and understand.

## Planned features
- Explore celestial objects and regions of the sky
- Learn how infrared observations reveal information beyond visible light
- Compare observations across survey epochs as data access allows
- Read clear explanations and links to official NASA/IPAC archive data

## Data
The project is designed around the official [NASA/IPAC SPHEREx archive](https://irsa.ipac.caltech.edu/Missions/spherex.html). Any sample content in the prototype will be labelled as illustrative, not live mission data.

## Status
Early prototype — interface and data integration are in progress.
